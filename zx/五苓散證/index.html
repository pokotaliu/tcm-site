MOC分流

MOC 入口（守則§11·2026-07-12）：凡「完整同比例」五苓散（澤瀉5:豬苓3:茯苓3:白朮3:桂枝2＝傷寒L342/金匱L556 逐字同·服法同「多飲暖水汗出愈」）所主＝同一病理結構（水停下焦、膀胱氣化不行）。型一方側鏡像（§11 四型 2026-07-12）：症狀邊由 0 級證型承載、本節點不重掛；梯級歸屬由治療列治法欄推得＝推測級可調。
梯級證型方形症狀相（演變）
0 原方主之太陽蓄水證（傷寒帶表形）五苓散原方消渴、小便不利、水入即吐（水逆）＋微熱脈浮
0 原方主之痰飲悸眩證（金匱無表形）五苓散原方臍下悸、吐涎沫、癲眩（水邪上冒清陽）
1 原方選用水飲內停證五苓散（溫陽化飲）水停泛化形
1 原方選用太陰虛寒證四逆輩證譜「渴者宜五苓散」（張錫純delta）太陰下利兼渴＝氣化不行之渴
2 輕加減脾氣虛證／脾經溼熱證／太陰寒溼鬱結證健脾行水／酌加藿蔻佩蘭／濕重於寒形重心移脾運（便溏、苔膩）
3 重加減·合方溼熱證（茵陳五苓散＝茵陳蒿末十分＋五苓散五分·金匱L713＝比例已變另方身份）茵陳五苓形黃疸軸
3 重加減·合方陽虛水泛證／腎陽虛水泛證／脾腎陽虛證／陽虛飲停證溫陽化氣行水（加減·合活血）水腫、肢冷、下利清穀軸
3 專科應用小兒元氣虛弱證／小兒溼熱內盛證／水輪水溼停聚證培補利水／濕重於熱／五輪專科語境

邊界（非本族·方劑鑑別）：茯苓甘草湯（不渴——傷寒L345「汗出而渴者五苓散主之;不渴者茯苓甘草湯主之」自帶辨眼）／苓桂朮甘湯證＝太陽水氣上逆證（中焦·心下逆滿目眩）／苓桂棗甘湯證＝太陽陽虛水氣欲衝證（臍下悸＋欲作奔豚L319——與痰飲悸眩形同見臍下悸，辨在伴隨徵：欲作奔豚 vs 吐涎沫癲眩）／豬苓湯（陰虛水熱互結）。
